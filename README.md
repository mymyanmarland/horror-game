# 👻 Horror Game — သရဲအိမ်

3D first-person survival horror game with 10 levels. Built as a single self-contained HTML file.

**Play:** https://mymyanmarland.github.io/horror-game/

- 🔦 Flashlight with battery management
- 👹 Enemy AI that hunts by light, sound and proximity
- 😮‍💨 Procedural audio — breathing, footsteps, heartbeat, jumpscares
- 📱 Touch controls for mobile
